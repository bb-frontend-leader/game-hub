# Game Hub Splash

haz una página con una interfaz muy divertida llena de colores y animaciones como Kahoot, en está pagina el usuario encontrara dos columnas con imagenes en cada una y un botón en cada una para dirigirse a dos juegos. ten encuenta en la parte superior el header para poner el logo a la derecha, a la izquierda un botón para ver la tabla de clasificación, el avatar y cerrar sesión.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
